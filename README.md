# Healthcare Analytics & Implementation Portfolio

Six case studies by **Cierra Reynolds, CPhT, CRCR, CSPR, CSBI**, built for three career tracks: Epic and clinical applications analysis, revenue cycle, and healthcare implementation and project management.

Each project turns a realistic healthcare operations problem into validated metrics, SQL analysis, findings, and specific recommendations.

**Live site:** https://ccreyn04.github.io/healthcare-analytics-portfolio/

## Skills demonstrated
- SQL (PostgreSQL): aggregation, CTEs, window functions, validation checks
- KPI design, root-cause and segmentation analysis
- Support ticket, SLA, and defect analysis
- Charge capture reconciliation, charge master review, denial and appeal analysis, A/R aging
- Implementation planning: charter, RACI, timeline, test and defect tracking, training, hypercare
- Power BI data modeling and DAX
- Executive-style findings with owners and measurable targets

## Analytical approach
1. **Define** the business decision, data grain, and KPI logic.
2. **Validate** record counts, dates, categories, and reconciliation totals.
3. **Analyze** volume, rate, value, variation, and aging.
4. **Recommend** specific actions, owners, and targets.

## Data ethics
All datasets are synthetic and contain no PHI. They were generated to demonstrate analytical method, so findings show how the analysis works and do not represent a real patient, payer, employer, or guaranteed result. No proprietary system screenshots or configurations are used.
