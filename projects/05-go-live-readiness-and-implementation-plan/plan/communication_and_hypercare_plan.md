# Communication and Hypercare Plan

## Communication plan
| Message | Audience | Channel | Owner | When |
|---|---|---|---|---|
| Project kickoff and timeline | Pharmacy staff, nursing leads | Email + staff meeting | Project coordinator | Week 1 |
| Weekly readiness report (gates, defects, risks) | Pharmacy leadership | One-page report | Project coordinator | Every Friday |
| Training schedule and make-up sessions | All affected staff | Email + posted schedule | Educator | 4 weeks before go-live |
| Go-live notice and what changes on the floor | Nursing units | Unit huddle + tip sheet | Super users | 1 week before |
| Escalation contact card | All pharmacy and nursing | Printed card at every station | Project coordinator | Go-live day |
| Daily top-issues update | Pharmacy leadership, IS | Short huddle + email | Application analyst | Daily during hypercare |

## Hypercare (14 days)
- A super user on every shift, including nights, for the first 14 days.
- Floor walkers in the pharmacy and on high-volume units for the first 3 days.
- Daily 15-minute huddle: top issues, new defects, workarounds in use.
- Issues triaged by priority: P1 same day, P2 within 8 hours.
- Manual refill backup for the automated cabinet interface for the first 2 weeks.
- Exit criteria: no open Critical issues, on-time order rate within 5 points of baseline for 5 days in a row, and ticket volume back to normal.
