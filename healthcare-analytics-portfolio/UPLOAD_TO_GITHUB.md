# Upload This Portfolio to GitHub

The prepared repository is named `healthcare-analytics-portfolio`.

## Recommended route

Once GitHub is connected, upload the **contents inside this folder** so
`README.md`, `projects`, `workbook`, and `website-source` appear at the
repository’s top level.

Use these repository settings:

- **Repository name:** `healthcare-analytics-portfolio`
- **Visibility:** Public
- **Description:** `Four end-to-end healthcare analytics case studies covering revenue cycle, claims denials, pharmacy operations, and prior authorization.`
- **Initialize with README:** No — this package already contains the completed
  README.

## After upload

1. Pin the repository on the GitHub profile.
2. Add these repository topics:
   - `healthcare-analytics`
   - `revenue-cycle`
   - `pharmacy-operations`
   - `sql`
   - `excel`
   - `data-analysis`
3. Add the final portfolio website URL in the repository’s **About** field.
4. Confirm all four dashboard images render in their project READMEs.
5. Open each CSV and SQL file once to confirm GitHub displays it.

The portfolio website’s GitHub buttons should link directly to:

`https://github.com/ccreyn04/healthcare-analytics-portfolio`
